엑셀 데이터 관리
인사이동 등 대량 변경은 현재 데이터를 내려받아 엑셀에서 고친 뒤 그대로 업로드합니다. 업로드 즉시 반영되지 않고, 차이 목록을 확인한 뒤 [반영]을 눌러야 적용됩니다.
1. 현재 데이터 다운로드
담당자 시트와 동일한 A~N열 양식으로 내려받습니다. 이 파일에서 행을 추가·삭제·수정한 뒤 업로드하세요. 파일 안의 [버전정보] 시트는 수정하면 안 됩니다.
2. 수정한 엑셀 업로드
사번 기준으로 현재 데이터와 대조해 추가·삭제·변경 내용을 미리 보여드립니다. 다운로드 이후 다른 변경이 승인된 파일(버전 불일치)은 경고가 표시됩니다.
보상서포터즈 업로드
취합해서 받으신 보상서포터즈 원본 엑셀(지역단·지점 행 + 분야별 사원번호·부서·성명·직위·전화번호 열)을 그대로 올리시면 됩니다. 양식을 바꾸지 않아도 자동으로 인식합니다.
임직원 명단 업로드 (사번 자동입력용)
인사에서 받은 임직원 명단 엑셀을 그대로 올리시면, 담당자 카드에서 사번만 입력해도 성명·직위·부서·전화·팩스·이메일이 자동으로 채워집니다. 명단이 갱신될 때마다 다시 올리시면 됩니다.
